案例背景
概述

公司信息

Contoso, Ltd 是一家跨国零售公司，通过使用 Microsoft Foundry 构建、部署和管理生成式 AI 和基于代理的解决方案。

现有环境

身份环境

Contoso 使用 Microsoft Entra ID 进行身份管理、身份验证和授权功能，使代理能够访问组织资源和服务。

Contoso 最近成立了一个新的 AI 工程团队，名为 Agent1Dev Team，以优化和维护现有的 AI 解决方案。

该团队与解决方案架构师、DevOps 工程师和安全工程师合作，设计、实施、监控和保护 AI 应用程序。

Contoso 还有一个名为 Agent1Test Team 的团队，负责在解决方案部署之前验证 AI 解决方案。

生成环境

Contoso 有一个 Microsoft Foundry 部署，其中包含两个项目，分别名为 Project1 和 Project2。

项目1

Project1 包含一个名为 Agent1 的客户支持代理，帮助客户处理产品咨询和故障排除请求。

Agent1 具有以下配置：

Agent1 使用基础模型部署。

安全评估管道 未 启用。

工具调用审批工作流 未 启用。

对话记忆约束 未 配置。

Agent1 通过数字支持渠道与客户互动，并回答有关 Contoso 产品的一般问题。

Project1 部署在位于欧盟 (EU) 的 Azure 区域。

Agent1Dev 团队将使用 Project1 来优化和维护 Agent1。

项目2

Project2 包含一个已部署的视频生成模型。Contoso 的市场部门可以访问 Project2，并计划使用该模型开发视频创作解决方案。

该解决方案的开发尚未完成。

数据环境

Contoso 在支持 AI 应用的 Azure 资源中存储与产品相关的信息。

Azure 环境包含一个名为 storage1 的 Azure Blob 存储帐户，该帐户存储所有 Contoso 产品的产品详细信息表。

产品说明书包括规格、功能描述和产品支持信息，Agent1 可以用来回答客户问题。产品说明书以 PDF 格式存储。

问题陈述

Contoso 确定了以下问题：

Agent1 仅对 Contoso 产品有一般了解。

最近与 Agent1 的聊天互动进行了情感分析。分析结果尚未 处理。

Agent1 在回答客户问题时，不使用存储在 storage1 中的产品说明书中的详细产品信息。

Contoso 的财务部门报告称，供应商发票必须手动审核，以确保发票与供应商合同中定义的条款相符。发票包含表格、徽标，以及各种布局，使得文件难以一致地处理。

需求

计划变更

Contoso 计划实施以下变更：

为 Project1 实施一个解决方案，通过评估发票的视觉布局和文本内容来分析供应商发票，以便能够根据供应商合同条款验证发票细节。

更新 Agent1 使用的基础模型部署，并标准化模型版本，以确保连续性和一致的响应。

启用 Agent1 从存储在 storage1 中的产品表中检索和使用详细的产品信息。

为产品表实施一个索引解决方案，以便 Agent1 可以用来回答客户问题。

完成视频创作解决方案的开发。

技术要求

Contoso 确定了以下技术要求：

Agent1 使用的模型部署必须支持可扩展的高吞吐量生成 AI 工作负载，并动态扩展以处理可变的客户支持流量，而无需保留吞吐量容量。

产品表必须通过使用索引管道进行处理，以支持语义和向量搜索，以便 Agent1 可以检索相关的产品信息。

使用产品表信息生成的响应必须相关、完整且准确。

Agent1 必须能够使用产品表回答有关产品详细信息的自然语言问题。

Agent1 使用的模型版本必须保持一致，以确保稳定的响应。

模型处理的数据必须保留在欧盟内。

安全和合规要求

Contoso 确定了以下安全和合规要求：

API 密钥必须 不 用于访问部署在 Foundry 的模型。

访问 Azure 资源必须遵循最小权限原则。

Contoso 的开发人员必须通过 Microsoft Entra 认证来访问 Microsoft Foundry 资源。

对 Project1 的访问必须通过名为 SC_Agent1_Dev 的安全组分配给 Agent1Dev 团队的成员。

对 Project1 的访问必须通过名为 SC_Agent1_Test 的安全组分配给 Agent1Test 团队的成员。

Agent1 绝不能泄露客户信息，即使包含客户数据的文档错误地添加到 storage1 的产品表存储库中。

产品表可能包含嵌入文本的图像。Agent1 必须受到保护，以防止潜在隐藏在图像中的恶意指令。

业务需求

Contoso 确定了以下业务需求：

与 Agent1 互动的用户必须在未来的互动中拥有个性化体验，包括 Agent1 能够保留对话上下文并回忆之前互动中的相关信息。

Agent1 只能回答有关 Contoso 销售的产品的问题。
您需要配置 Agent1 以满足安全和合规要求。
